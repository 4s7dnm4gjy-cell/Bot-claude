# TrackPlan

Outil gratuit d'athlétisme (FR/EN) : plan d'entraînement périodisé par discipline,
temps de passage sur piste et prédiction de performance (formule de Riegel).
Site statique sans dépendance : ouvrir `index.html` via un serveur
(`python3 -m http.server`) ou déployer le dossier tel quel sur Vercel.

Pour activer le bouton de liste d'attente Premium, renseigner `WAITLIST_URL` dans `app.js`.
